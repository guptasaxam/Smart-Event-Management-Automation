# Stakeholders

The Smart Event Management Automation System involves multiple stakeholders, each interacting with the system in different ways.

---

## 1. Event Organizers

Event organizers are the primary users of the system. They are responsible for managing participant registrations, monitoring attendance, and ensuring certificates are distributed successfully.

### Responsibilities

- Create and manage events
- Monitor participant registrations
- Verify attendance records
- Track certificate generation and distribution
- Access participant data stored in Google Sheets

---

## 2. Participants

Participants register for events and receive automated communication throughout the event lifecycle.

### Responsibilities

- Submit registration details
- Attend the event
- Receive QR code for attendance verification
- Receive participation certificate via email

---

## 3. Event Volunteers

Volunteers assist organizers during the event by verifying participant attendance and ensuring smooth event operations.

### Responsibilities

- Verify participant attendance
- Assist participants during registration
- Support attendance tracking

---

## 4. System Administrator

The system administrator manages the automation workflows and maintains the technical infrastructure.

### Responsibilities

- Configure n8n workflows
- Manage Google Workspace integrations
- Monitor workflow execution
- Handle system errors and maintenance
- Ensure data integrity and security

---

## Stakeholder Interaction

| Stakeholder | Role |
|--------------|------|
| Event Organizer | Manages registrations, attendance, and certificates |
| Participant | Registers, attends the event, and receives certificates |
| Event Volunteer | Assists with attendance verification |
| System Administrator | Maintains workflows and integrations |
